# Prompt queue

Ordered work queue for Claude Code. Protocol: when asked to "take the next task from the queue" (or similar), pick the FIRST item with status `pending`, set it to `in_progress` (edit this file), execute the referenced prompt file fully, and when everything is green (`pytest`, `npm run lint`, `npm run build`) set it to `done` with today's date. Do exactly ONE item per request unless explicitly told to continue. If an item fails partway, leave it `in_progress` and note the blocker under it.
